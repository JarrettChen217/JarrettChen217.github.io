# 项目照片待选区 / Project photo inbox

把照片、截图或演示素材拖进对应项目目录即可。目录名与 projects.yml 的项目 ID 对齐；dance-xr、cat-crossing、cosmic-creators 是待整理项目，不代表已经上线。

这些文件默认被 Git 忽略，不会自动进入项目页面。请不要强制加入 Git。发布前单独筛选、检查照片中人员的公开意愿、移除敏感信息与位置等 EXIF 元数据，再将经过确认的副本放入公开资源目录并在 projects.yml 中显式引用。

Git 忽略不是访问控制：从仓库根目录启动的本地文件服务器仍可能通过路径读取这里的文件。当前预览应只绑定 127.0.0.1；请勿用隧道或整目录上传分享此目录。不要放证件、密钥、客户/学生资料或内部文档。

建议文件名（不强制）：01-overview.png、02-before.png、03-after.png、04-team.jpg。中文文件名也可，后续引用前再整理。

- berry-street：同一任务的低保真/高保真 Figma 截图、仪表盘改版前后、你选择的 Max 与团队合照。
- avl-visualisation：树旋转关键步骤、伪代码与树图同步画面、递归播放问题示例、团队合照。
- dance-xr：头显实机画面、minimap 操作、VIVE 校准界面、设备或团队照片。
- 其他目录：项目总览截图、一个关键交互、可公开的团队照片。

只需提供你想展示的图片；不用一次填满所有目录。保持原始文件，裁剪与压缩只处理副本。合照不是证明项目完成度的依据，不会自动推断人物姓名、身份或贡献。

English: Drop candidate assets into the matching project folder. Files remain untracked and are not automatically rendered. This is an intake folder, not a secure vault; review consent, rights and metadata before explicitly selecting public copies.
